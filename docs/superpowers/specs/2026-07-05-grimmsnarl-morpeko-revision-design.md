# マリィのグリムスナールex デッキ 第3次改修：モルペコ再導入によるイワパレス対策 設計書

**作成日：** 2026-07-05
**背景：** 環境上位の「イワパレス」に対して勝ち手段が無いという問題に直面した。原因を調査したところ、イワパレス（Card ID 345/533）は特性「しんぴのいしやど」で**相手の「ポケモン【ex】」からの技ダメージを一切受けない**ことが判明した。現行デッキのアタッカーはグリムスナールex・キチキギスexの2体ともexであり、イワパレスにダメージを与える手段が実質存在しない。あわせて、現行デッキのユキワラシ・ユキメノコ（Froslass）ラインが「展開の遅さ」と「特性持ちポケモンへの自傷ダメージによる事故（キチキギスexとオーロンゲexが同時気絶する場面が過去にあった）」の原因になっていることも合わせて整理する。

---

## ゴール

1. 非exアタッカー「マリィのモルペコ」を再導入し、イワパレスに対しても通るダメージ手段を確保する
2. 自傷ダメージ・展開の遅さの原因になっているユキワラシ・ユキメノコ（Froslass）ラインと、その前提が崩れるマシマシラ（Munkidori）を完全撤去する
3. 空いた枠を、デッキの性質（アグロ〜バーストテンポ）に合った展開速度・ドロー補強に再配分する

## 調査で判明した事実

### イワパレス（ID 345 / 533）
> 特性「しんぴのいしやど」：このポケモンは、相手の「ポケモン【ex】」からワザのダメージを受けない。

現行デッキのアタッカーは以下の2体のみで、両方exのため通用しない：
- マリィのオーロンゲex（648）：シャドーバレット 180+ベンチ30
- キチキギスex（140）：クルーエルアロー 100

### ユキメノコ（Froslass, ID 104）の特性「いてつくとばり」
> このポケモンがいるかぎり、ポケモンチェックのたび、おたがいの特性を持つポケモン（「ユキメノコ」をのぞく）全員に、それぞれダメカンを1個のせる。

ダメージが**自分・相手の両方**にかかる。ユキメノコ2体だと1ターンに自分側だけで2ダメカンが特性持ち全員（グリムスナールex・キチキギスex含む）に蓄積し、ユーザー報告の「キチキギスとオーロンゲが同時に気絶する」事故の原因になっていた。加えて、ユキワラシ→ユキメノコの進化（2ターン）自体が展開を遅くしている。

### マシマシラ（Munkidori, ID 112）
特性「アドレナブレイン」（自分の場のダメカンを最大3個相手に乗せ替え）は、当初「フロスラスの副産物ダメカンを転嫁する」ためのコンボだった。フロスラス撤去によりこの前提が崩れるため、あわせて撤去する。

### マリィのモルペコ（ID 649、ex無し）
> わざ「スパイクホイール」：無色●●●で20+**このポケモンについている悪エネルギーの数×40**ダメージ

非exであるため、イワパレスの特性を回避してダメージを通せる。「マリィのポケモン」であるため、グリムスナールexの特性「パンクアップ」（進化させた番に山札から基本悪エネルギー最大5枚を自分の「マリィのポケモン」に自由配分）の対象にできる。

### カードプール上の制約（確認済み）
- 「ネモ」「ナンジャモ（サポート単体）」「すごいつりざお」は`data/JP_Card_Data.csv`に**存在しない**（マスカーニャexと同様、収録外）
- 近い効果の「つりざおMAX」（ID 1110）はACE SPECであり、既にSecret Box（ID 1092）でACE SPEC枠（1デッキ1枚まで）を使い切っているため採用不可
- 現行デッキの(1227)は実データ上「リーリエの決心」（手札を山札に戻し6枚引く／自分のサイド残り6枚なら8枚引く）であり、ナンジャモに近い全リセット効果を既に4枚（上限）採用済み

- **Rare Candy 4枚目：** 「多すぎても事故の元」というユーザー判断で見送り、3枚維持
