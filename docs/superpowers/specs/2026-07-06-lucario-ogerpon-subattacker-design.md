# ルカリオexデッキ サブアタッカー「オーガポン いしずえのめんex」導入 設計書

**作成日：** 2026-07-06
**背景：** バトルログ6件（84247835, 84263756, 84282643, 84272494, 84284704, 84278857）の勝敗解析により、ルカリオexデッキの敗因は「①ミラー戦のテンポ遅れ」「②Cynthia's Garchomp exなどとの純粋な火力負け」「③Grimmsnarl ex/Dragapult exのベンチ広範囲ダメージによる削り負け」の3パターンに整理できた。加えて、グリムスナールexデッキの調査で「イワパレス（特性で相手ポケモンexの技ダメージを無効化）」という環境上位デッキに対して既存アタッカーが軒並み無力という問題が判明しており、ルカリオexデッキの環境でも同種の特性持ち耐性ポケモンが今後登場しうる。この対策として、非ex/ex問わず特性持ちポケモンからの技ダメージを受けず、かつ弱点・抵抗力・相手バトル場の効果を無視して確実にダメージを通せる「オーガポン いしずえのめんex（Cornerstone Mask Ogerpon ex, Card ID 117）」をサブアタッカーとして導入する。

---

## ゴール

1. オーガポン いしずえのめんex（ID 117）を1枚デッキに採用し、メガルカリオexに次ぐサブアタッカーとして機能させる
2. 導入目的は「特性持ちポケモン対策」（新規の想定シナリオへの備え）であり、現行6試合の敗因①②③に直接対応するものではないことを明記する
3. エージェント側は特別な「相手の特性検知」ロジックを持たず、既存の`calc_attack_plan`の枠組みに汎用サブアタッカーとして組み込む（実際のダメージ・効果適用はシミュレータ本体が正しく処理するため、エージェントは「攻撃する」選択をするだけでよい）

## 変更内容：エージェントロジック（`src/lucario_agent/main.py`）

### アプローチ：既存パターンへの最小差分追加

現在`calc_attack_plan`はMega Lucario ex（通常技/メガブレイブ）とSolrock（ルナトーン依存の技）をif/elif連鎖で扱っている。オーガポンexも同じ形で3つ目の分岐として追加する。テーブル駆動化（案2）も検討したが、現状アタッカーは3種のみであり、YAGNIの観点および既存コードスタイル（グリムスナールデッキのモルペコ追加時と同じ手法）との一貫性から見送る（詳細は「将来の検討事項」参照）。

#### ①カードID定数の追加
```python
Ogerpon_ex = 117  # Cornerstone Mask Ogerpon ex
```

#### ②`calc_attack_plan`：アタッカー候補として追加
```python
elif my_pokemon.id == Solrock:
    if field_counts[Lunatone] >= 1:
        energy_required = 1
        base_damage     = 70
elif my_pokemon.id == Ogerpon_ex:
    energy_required = 3
    base_damage     = 140
```

#### ③弱点・抵抗力の無視（ぶちやぶるの効果を反映）
技「ぶちやぶる」は「弱点・抵抗力を計算しない」ため、ダメージ計算の共通ブロックをオーガポンexのときだけスキップする。
```python
damage = base_damage
data   = card_table[op_pokemon.id]
if my_pokemon.id != Ogerpon_ex:
    if data.weakness == EnergyType.FIGHTING:
        damage *= 2
    elif data.resistance == EnergyType.FIGHTING:
        damage -= 30
```

#### ④`energy_score`：エネルギー配分の優先度
ルカリオへの供給を阻害しないよう、「ルカリオ系統がまだ準備不足なら控えめ、準備済み（`attacker1`）なら余剰エネルギーを回す」という、グリムスナールデッキのマシマシラと同じパターンを踏襲する。
```python
elif pokemon.id == Ogerpon_ex:
    if energy_count < 3:
        score += 80
    if attacker1:
        score += 40  # ルカリオ確保済みなら余剰エネルギーをオーガポンexへ
```

#### ⑤`_score_card_option`のDISCARDケース：誤トラッシュ防止
1枚しかないため、既存のRiolu/Mega Lucario ex/Solrock/Lunatoneと同様に保護対象に加える。
```python
if card.id in (Riolu, Mega_Lucario_ex, Solrock, Lunatone, Ogerpon_ex):
    return -100
```

### 変更しない箇所（意図的にスコープ外）
- **[特性]いしずえのかまえ・技の「相手バトル場の効果を無視する」部分**：実際の効果適用はシミュレータ本体（libcg.so）が正しく処理するため、エージェント側の内部ダメージ見積もりには反映しない。見積もりが一部シナリオで甘くなる可能性はあるが、行動選択自体（「攻撃する」の選択）には影響しない
- `_analyze_main_options`のattackId=983判定：オーガポンexは技が1つのみで曖昧さがないため変更不要
- `_score_option`のATTACKケース：デフォルトロジックのままで単一技のオーガポンexは問題なく選択される
- SWITCH/TO_ACTIVE・TO_HAND（サーチ）スコアリング：特別なブーストは付けず、既存の汎用ロジック（`current_plan.attacker`一致ボーナス／デフォルトのサーチ優先度200点）に委ねる。1枚だけのテックカードという位置づけに合わせ、変更は必要最小限に留める
