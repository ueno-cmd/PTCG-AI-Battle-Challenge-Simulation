## 実装した主な機能

### 1. テーブル駆動の4アタッカー体制
`ATTACKERS`（`src/jamoraiko_agent/main.py:123-134`）にポケモンID・技名・必要エネルギー数・ダメージ計算関数・次ターン技封じフラグ・ユーティリティ技フラグをまとめたテーブルを定義し、`calc_attack_plan()`が以下の優先順位で技を選定する。

1. 確定KOできる技があれば、場のエネルギーを消費しない技を優先する（きょくらいごうは他に確定KO手段がない場合のみ使用）
2. 確定KOがなければ最大ダメージを選ぶが、次ターン技封じ技（ハラバリーexのサンダーボルト等）は評価を150ダメージ分減点する
3. はじけるほうこう（ダメージ0のユーティリティ技）は他に使える技がない場合のみ自然に選ばれる

対応技：ビリリダマ「ボルテックスチェイン」、ハラバリーex「サンダーボルト」、タイカイデン「マッハボルト」、タケルライコex「きょくらいごう」「はじけるほうこう」。

### 2. attackIdの動的解決
`cg.api`はKaggle実行環境でしか使えないため、attackIdをマジックナンバーで決め打ちせず、`_attack_id_by_name()`（`main.py:253-259`）が`all_attack()`から構築した`attack_table`を技名で逆引きする方式にした。これによりローカル開発環境でのユニットテストとKaggle実行環境の両立を実現している。

### 3. 山札セーフティの統合
ルカリオexデッキで確立した`_safe_draws`/`_deck_consumption`パターン（`87c9ca8`までの一連のコミット）をジャモライコにも移植した。
- `_safe_draws(my_state)`：残りプライズ数を残りターン数の見積もりとして使い、毎ターンの必須ドロー分を温存してデッキアウトを防ぐ
- `_deck_consumption()`：リーリエの決心（プライズ枚数に応じて6枚 or 8枚ドロー）の正味消費枚数を計算
- `_flashing_draw_consumption()`：タイカイデンの特性「フラッシュドロー」（手札が6枚になるまでドロー）の消費枚数を計算
- はじけるほうこう・リーリエの決心・特性フラッシュドローの発動判断に、いずれも`_safe_draws()`との比較によるガードを組み込み済み

### その他の実装要素
- `FieldState`収集ヘルパー（`_collect_field_state`）：バトル場・ベンチ・手札・捨て山の枚数とダメージ計算に必要なエネルギー集計（チェインボルト/きょくらいごう用）を1箇所に集約
- `energy_score()` / `_score_attach_option()`：雷エネルギーは攻撃射程に近いポケモンを優先、闘エネルギーはタケルライコexを優先する装填スコアリング
- `_score_play_option()` / `_score_option()`：PLAY・ATTACH・EVOLVE・ABILITY・ATTACK等の各OptionTypeに対するヒューリスティックスコアリングを統合し、`agent()`が最終的にスコア降順で選択肢を返す
