# 実装サマリー：グリムスナールexデッキ「控えポケモン誤出場」バグ修正（フェーズA）

**実装日：** 2026-07-03
**関連ドキュメント：** `docs/reviews/20260703-grimmsnarl-switch-scoring-investigation.md`

## 背景

ユーザー報告「スコア431〜624の乱高下。控えに出さないといけないポケモンをバトルフィールドに出してしまっている。勝ち方も美しくない」を受け、バトルログ6件（`83347688`/`83433347`/`83438721`/`83444801`/`83474441`/`83502424`）を解析。`SWITCH`/`TO_ACTIVE`選択時のスコアリングが同点になると安定ソートでベンチ0番目が機械的に選ばれてしまい、特性専用の低HPポケモン（スボミー30HP、被弾済みコダック40HP等）が実戦向きのイベルタル(110HP)等を差し置いて誤って前に出ていたことが根本原因と特定した。

## 変更内容（`src/grimmsnarl_agent/main.py`）

### カードID定数・`SUPPORT_ONLY_IDS`追加
- `Froslass`(104)／`Budew`(235)／`Shaymin`(343)／`Tatsugiri`(122)／`Yveltal`(689)／`Psyduck`(858)を定数化
- 場にいるだけで無条件に特性を発揮する専用要員（Froslass/Budew/Shaymin/Tatsugiri/Psyduck）を`SUPPORT_ONLY_IDS`としてまとめた。マシマシラ(Munkidori)は特性発動にエネルギー要求があり攻撃も可能なため対象外とした

### `_score_own_switch_target`修正
- グリムスナールex：`10000 + エネルギー数*2`（最優先は維持）
- `SUPPORT_ONLY_IDS`所属：`-1000 + HP`（他に選択肢がある限り選ばれない負のスコア域）
- それ以外：`HP + エネルギー数*2`（残りHPが高い実戦向きポケモンを優先）

### `_score_attach`修正
- グリムスナールexがシャドーバレット分（悪エネルギー2枚）を確保済み（`fs.grimmsnarl_energy_count >= 2`）かつマシマシラがエネルギー未装着の場合のみ、基本エネルギーをマシマシラへ分配できるようにした（スコア4000）
- これによりマシマシラの特性「アドレナブレイン」（エネルギー1枚で発動）が実際に機能するようになった。以前はグリムスナールex以外への基本エネルギー付与が常に`-1`で、3枚採用しているにもかかわらず特性が永久に発動しなかった

## テスト結果

- `uv run pytest -q`（リポジトリ全体）177件全PASS、既存テストの回帰なし
