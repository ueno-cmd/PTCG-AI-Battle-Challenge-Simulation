- 目的: ユーザー報告の「20戦勝率45%」（前回検証65%から大幅下落）の原因究明。直近3改修が退行を招いていないか、Kaggleビジュアライザー観戦でユーザーが気づいた4点の裏取り
- 手法: 3本のバックグラウンドエージェントに「敗戦5戦深掘り×2」「20戦マクロ分析」を分担させ、生JSONの`observation.logs`（LogType）を直接解析。加えてcontroller自身が`src/lucario_agent/main.py`のスコアリングロジックを監査し、ユーザー指摘との整合性を検証

## 結論（先に要点）

- **20戦全体：10勝10敗（50%）**。ユーザー報告の45%とは完全一致しないが近い値（Kaggle側の集計範囲の違いの可能性、要ユーザー確認）
- **直近3改修（ex無効化汎用化・スタジアム考慮・Ogerpon ex優先度連動）は退行の原因ではない**：
  - ex無効化検知（Crustle/Sylveon）は複数戦・複数回の実測で正確に動作（exの攻撃は確実に0ダメージ、非exやOgerpon exの「効果無視」技は確実に実ダメージが通過）
  - スタジアム考慮（Nighttime Mine）は20戦中一度も出現せず、今回は実戦未検証（バグの有無どちらも確認できず）
  - Crustle系デッキとの遭遇率は前回検証（65%期）も今回も同じ20%（4/20戦）。前回は1勝3敗(25%)、今回は0勝4敗(0%)で、n=4の小サンプルでの結果反転にすぎない
- **新規に確定した実バグ（本セッションの主要発見）**：`calc_attack_plan`の攻撃プラン選択で、現在アクティブなポケモンを優先する「居座りボーナス」（`i==0`で+220、`j==0`で+300、main.py:387-390）が実ダメージの多寡と無関係に加算されるため、**Crustleに対し0ダメージと分かっている攻撃が、実ダメージの出る控えのSolrock/Ogerpon exへの切替より高スコアになるケースがある**。さらにRETREATの選択スコアが`current_plan.attacker >= 1`のみに依存する二段構え（main.py:753）のため、この誤ったプラン選択がそのままそのまま「交代しない」という行動選択に直結する。試合86898758で実測：ターン相当のstep29〜49の間、RETREATの選択肢自体は一貫して提示されていたが、9ターン連続でMega Lucario exの0ダメージ攻撃が選ばれ続けた
- **ユーザーがKaggleビジュアライザー観戦で気づいた点はすべて上記バグと整合**（詳細は「3. ユーザー所見との対応」参照）
- **環境トレンド**：Mega Lucario exミラー戦の出現率が前回20戦の1/20(5%)→今回5/20(25%)に増加。ミラー相手はサンプル内で100%「Carmine」（ID1192、先攻1ターン目限定・手札全捨て5ドロー）を採用。今回のミラー戦績は4勝1敗(80%)で現状負け越してはいない

## 3. ユーザー所見との対応

Kaggleビジュアライザーでの観戦により、以下4点の気づきが共有された。いずれも上記の「居座りボーナス」バグで統一的に説明できる。

1. **「ソルロックにエネルギーつけすぎ」**：`energy_score`のスコア配分により、Crustle戦で本来主力になるべきOgerpon exより先にSolrockへエネルギーが偏る場面がある
2. **「オーガポンが戦えるのに、ベンチのルカリオにエネルギーが回っている」**：同上。`op_active_nullifies_ex`時のOgerpon ex優先度ボーナス（+150、main.py:179-180）はあるが、Mega Lucario ex/Rioluの`energy_count < 2`時+100ボーナスと競合し、必ずしもOgerpon ex優先が確保されない
3. **「相手がイワパレスなのに交代せず殴ろうとする」**：本セッションの主要発見そのもの。試合86898758ではRETREATの選択肢自体は提示されていたが、`calc_attack_plan`の居座りボーナスにより0ダメージ攻撃のプランスコアが実ダメージの出る控えより高くなり、9ターン連続で交代しなかった
4. **「ベンチに手張りすると逃げられない」**：デッキに自分から交代するための「スイッチ」系トレーナーズが1枚もなく（ボスの指令は相手専用）、自分の交代は「にげる」＝アクティブ自身のエネルギーで逃げコストを払う一択。試合86898758の序盤（RETREATが選択肢に出ていなかった期間）はこの構造が実際に交代を妨げていたことを確認。ただし中盤以降（RETREATが選択肢に出てからも交代しなかった期間）は3.の居座りボーナスバグが主因
