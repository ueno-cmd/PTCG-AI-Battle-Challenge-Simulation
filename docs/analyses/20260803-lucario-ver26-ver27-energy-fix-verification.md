## 結論（先に）

**修正は成功した。** 狙った2つの挙動は**74〜86%減**り、懸念されていた副作用は**実質的に発生していない**。

そのうえで、**次に手を付けるべき最大の残課題が数値で確定した**：
**オーガポンexが「バトル場にエネを付けた同じターンに退却し、そのエネを退却コストで捨てる」浪費が
31戦で17枚**。これはバトル場への全装着103回の**約17%**にあたり、修正前からほぼ手つかずで残っている。
これはバックログの保留項目「原因3：オーガポンexのデッドロック」そのもので、**保留を解除して着手する条件が揃った**。

## 重要な前処理：相手の事故勝ち9件を除外した

生の40戦をそのまま比較すると誤った結論に至る。修正後バッチには
**「相手がターン1で応答不能に陥って敗北した試合」が9件**含まれていた（修正前は1件）。

例（`88783510`）：ターン1、双方の盤面は無傷（こちらソルロック110HP／相手344が70HP、両者ベンチ0・サイド6）。
相手の手番で9ステップ何も起きずに`DONE`となり`rewards=[-1,1]`。**こちらは1枚もサイドを取っていない。**
相手側のエージェント事故であり、我々のプレイとは無関係。

これらは我々の行動をほとんど含まないため、**残すと分母（自分のターン数）だけが縮んで
全ての「1ターンあたり」指標が2割ほど水増しされる**。実際、除外前は副作用指標が軒並み+19〜24%に見えたが、
除外後は+6〜10%に収まった（＝副作用は無い、が正しい）。

除外基準：**勝ち試合のうち、終局時点で自分のサイドが6枚残っている（＝1枚もサイドを取っていない）もの**。

| | 修正前 ver24+25 | 修正後 ver26+27 |
|---|---|---|
| 生の試合数 | 40戦 | 40戦 |
| 相手の事故勝ち（除外） | 1戦 | **9戦** |
| **有効試合数** | **39戦** | **31戦** |
| 自分のターン数（分母） | 303 | 215 |

除外した9件: `88778193` `88783510` `88784593` `88786195` `88788366` `88797654` `88798724` `88799753` `88807298`

回数そのものは試合数・ターン数が違うので、**100ターンあたりに正規化**して比較する。

| エネルギー破棄の総枚数 | 53枚 | 19枚 | 17.5 → 8.8 (-50%) | ✅ |
| **バトル場0エネなのにベンチへ装着** | 30回 | **3回** | 9.90 → **1.40 (-86%)** | ✅ |

- **原因1（DISCARDで闘エネを捨てる）の修正**：DISCARDの機会に対する比率で見ると
  **20.3%（16/79）→ 6.7%（3/45）**。3分の1に減った
- **原因2（0エネのバトル場を放置してベンチに付ける）の修正**：30回 → 3回。
  正規化しても-86%で、**ほぼ消えた**

## 最大の残課題：オーガポンexの「装着→同ターン退却」浪費（新規に数値化）

副作用(b)を掘ったところ、**修正とは無関係な、以前から存在する別の大きな漏れ**が見つかった。

実ログ`88778720`のstep62〜64がその典型：

1. step62（ターン7）：バトル場のオーガポンex（0エネ）に基本闘エネを**装着** → `energies=[6]`
2. step63（同ターン7）：**退却**を選択
3. step64（同ターン7）：退却コストとして、**いま付けたばかりのそのエネを破棄** → `energies=[]`

**そのターンのエネルギー装着権を1回使って、同じターンに捨てている。**

| | 修正前 (39戦) | 修正後 (31戦) |
|---|---|---|
| 同ターンに装着したエネを退却コストで喪失 | **25枚** | **19枚** |
| 　うち **オーガポンex** | **23枚** | **17枚** |
| 　うち ソルロック / ルナトーン | 2枚 | 2枚 |
| 　うち装着時点でバトル場が0エネだった | 24枚 | 18枚 |

- **修正前から24枚あった**ので、**2026-07-29の救済ボーナス(+300)が作り出した副作用ではない**
  （＝この修正の責任ではない、独立した既存の穴）
- 修正後も**バトル場への全装着103回のうち17枚（約17%）**がこの形で捨てられている
- 犯人はほぼオーガポンex一択。**技「ぶちやぶる」は闘エネ3個必要／にげるコストは1**という
  カード特性上、「攻撃には遠く、退却には1個だけ払える」状態が生まれやすい

### なぜ起きるか（構造）

バトル場が0エネのオーガポンexに対し、
- `_score_attach_option`の救済ボーナス(+300)が「0エネのバトル場に付けろ」と言う
- 一方で`_score_retreat_option`は「このターン攻撃できないなら退却しろ」と言う

この2つが**同じターン内で両方発火**し、付けた直後に退却コストとして消える。
救済ボーナスは「0エネだと退却コストすら払えないデッドロック」を解くために入れたものなので、
**「退却するために1個付ける」動作は設計意図の範囲内**とも言える。
問題は、**その後オーガポンexが再びバトル場に戻ってきて同じことを繰り返す**点にある
（`88778720`ではターン7と15の2回、`88779800`でもターン7と13の2回）。

## 勝率について（判断材料にはしない）

[[feedback_process_metrics_over_winrate]]のとおり、20〜40戦の勝率では効果判定はできない（要97戦以上）。
参考値としてのみ記録する。

| | 修正前 ver24+25 | 修正後 ver26+27 |
|---|---|---|
| 生の勝率 | 19勝21敗 (47.5%) | 21勝19敗 (52.5%) |
| **有効試合のみ** | 18勝21敗 (46.2%) | 12勝19敗 (38.7%) |
| **自力のサイド勝ち**（終局時サイド残0-1） | 7件 / 39戦 (17.9%) | 8件 / 31戦 (25.8%) |
| 相手の事故勝ち | 1件 | 9件 |

**生の勝率が+5pt上がって見えるのは、相手の事故勝ちが1件→9件に増えたことがすべて**。
分散の小さい「自力のサイド勝ち」は7件→8件（17.9%→25.8%）で、方向としては良いがn=8では断定できない。

なお**勝ち試合の平均ターン数は11.1→7.1（Welch t=2.70, df=30.2, 両側p=0.011）**と有意に短縮したが、
これも短い事故勝ちに引っ張られた結果であり、**有効試合の自力勝ちに限れば13.7→9.2ターン**。
サンプルが7件と8件なのでこちらは参考値。

## 分析ツールに関する記録

### 計測スクリプトへの追加（本セッション）

`scripts/analyze_lucario_energy_metrics.py` に副作用指標2つを追加（TDDで実装、テスト21件全PASS）。

- `measure_supporter_discards()` — 副作用指標(a)。サポート = `1182 Boss's Orders` /
  `1213 Judge` / `1227 Lillie's Determination`（`EN_Card_Data.csv`のCategory列で確認）
- `measure_retreat_energy_loss()` — 副作用指標(b)。
  戻り値 `retreats` / `energy_lost` / `lost_attached_same_turn` / `lost_attached_prev_turn`
- 併せて`measure_energy_discards`内のクロージャ`_hand_card`をモジュール関数に抽出し、
  サポート版と共通化（重複実装を避けた）

### ログ構造の知見（罠の追加）

- **退却コストの支払い形式**：`OptionType.RETREAT(12)`を選んだ**直後**の
  `SelectType.ENERGY(4)` / `SelectContext.DISCARD_ENERGY(30)` で、捨てるエネルギーを選ぶ。
  `DISCARD_ENERGY`は相手の技の効果等でも発生するため、**直前のRETREAT選択と紐付けたものだけ**を
  「退却で失った」と数えないと過大計上になる
- **罠8（新規）**：**相手側の事故で終わった試合を混ぜると、分母（自分のターン数）だけが縮み、
  1ターンあたりの指標が一律に2割ほど水増しされる。** 今回は除外前後で副作用指標の判定が
  「+19〜24%（悪化に見える）」→「+6〜10%（横ばい）」と逆転した。
  **勝ち試合の終局サイド残が6（＝1枚も取っていない）ものを除外すること**
- 山札の中身は自分視点でも見えない（`deckCount`のみ）。デッキ60枚の完全一致検証は
  ver23分析と同じ方法では取れないため、今回はカードIDの出現集合で同一デッキであることを確認するに留めた
