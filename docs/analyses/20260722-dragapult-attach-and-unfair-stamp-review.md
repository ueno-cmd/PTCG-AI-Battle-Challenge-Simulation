# ドラパルトex 20戦分析：エネルギー配分先とアンフェアスタンプの使い所（2026-07-22）

対象ログは`docs/analyses/20260722-dragapult-boss-orders-evolution-20-games.md`と同じ20戦（`87204277`〜`87214695`）。ユーザーから「バトル場ではなくベンチにエネルギーがいった理由」「アンフェアスタンプの使い所は合っていたか」の所感を受けて調査した。

## アンフェアスタンプ（ID1080）：バグなし（当初「確定バグ」と誤報告→訂正済み）

**結論：現状のスコアリングは実際のカード条件と一致しており、問題なし。**

`main.py`の`hand_score()`は`if pre_ko: score = 80000`（`pre_ko`=前ターンに自分のポケモンが気絶したか）で最優先スコアを与えている。実際のカード効果は「前の相手の番に自分のポケモンが気絶していた時のみ使用可」（`data/competition/JP_Card_Data.csv`・`EN_Card_Data.csv`とも同じ条件で一致）であり、コードのロジックは正しい。

**調査時の誤り（一時的に「確定バグ」と誤報告した経緯）：**
1. JP原文「自分のポケモンがきぜつしていなければ使えない」を「気絶していなければ使える」と誤読していた。正しくは二重否定で「気絶していれば使える」（気絶が使用条件）
2. 裏取り用に書いた検証スクリプトに2つのバグがあった：①1つの観測ステップに複数ターン分のログが混在するケースを考慮せず、ステップ境界で前ターンの範囲を誤判定していた、②`AreaType`（DISCARD=3, ACTIVE=4, BENCH=5等）の数値コードを確認せず憶測の値を使っていた
3. この2つのバグにより、実際は「9/9戦とも気絶直後に使用されていた」という正しいデータが「9/9戦とも気絶していない時に使用されていた」という逆の結果に見えてしまっていた

修正後のスクリプトで9回の実使用を再検証した結果、全て「自分のポケモンが前の番に気絶していた」場面での使用と確認できた。ロジック修正は不要。

## ベンチへのエネルギー配分

- 65回のベンチ向けエネルギー装着のうち、アクティブが本命技（ファントムダイブ、2エネ必要）を撃てる状態でなかったケースが44件
- 内25件はスボミー/フェザンディピティex/ラティアスex/ニャースexが場にいた場合で、これらは`attach_score()`の専用分岐によりそもそもエネルギーを受け取らない設計（問題なし）
- 残り19件（ドラメシヤ/ドロンチ/ドラパルトexがアクティブで、まだエネルギーを必要としているのにベンチへ回った）は、スコア式の大枠は追えたが、`bench_attacker`・`can_switch`・毒/マヒ状態など当時のグローバル状態を完全再現できておらず、意図通りかは**未確定のまま保留**（次回持ち越し）

## 教訓

外国語カードテキストの否定構文は誤読しやすい。「〜していなければ使えない」のような二重否定は、日本語ネイティブでも一度立ち止まって論理的に検算すべき（[[feedback_verify_analysis_claims]]と同じ精神で、条件文の解釈も実測データで裏取りしてから断定する）。
